# Astro-Zodiac — Product Blueprint

## 1. Product Philosophy

Astro-Zodiac is not designed to be only an astrology report generator.

The product journey is:

```text
FREE = Discovery
    ↓
PAID 99 = Validation
    ↓
PAID 599 = Action
    ↓
PAID 1,999 = Transformation
```

Each upgrade must deliver a materially new outcome, not simply a longer report.

## 2. Product Objective

The system must help a user move through four questions:

1. ฉันเป็นอย่างไร?
2. จุดที่ฉุดฉันคืออะไร?
3. ฉันควรเปลี่ยนอย่างไร?
4. ฉันต้องทำอะไรต่อ?

Core product loop:

```text
Astrology / Uranian
→ Pattern / Blind Spot
→ Validation
→ Psychology / Intervention
→ Action Plan
→ Worksheet
→ Tracking
→ Progress
→ Next Plan
```

## 3. Positioning

Primary positioning:

> Personal Development Intelligence Platform

Core message:

> Discover Your Patterns. Change Your Life.

Thai direction:

> ค้นพบ Pattern ของตัวเอง เพื่อเปลี่ยนชีวิตให้ดีขึ้น

Do not position the product primarily as:
- "AI ดูดวงแม่น"
- "AI ทำนายอนาคต"
- Clinical diagnosis

Astrology and Uranian methods are used as pattern-discovery tools. Validation and user-reported behavioral evidence are required before stronger personal-development conclusions are made.

## 4. Package Ladder

### Package 1 — FREE INSIGHT

**Role:** Discovery / acquisition.

**Goal:** Create an accurate-feeling Aha Moment without giving away the complete solution.

**User receives:**
- 1–2 major patterns or blind spots
- selected strengths
- a brief explanation of relevant astrological signals
- a clear statement that the pattern is something to explore/validate
- teaser of additional analysis

**Free must not:**
- deliver a complete transformation plan;
- present the output as psychological diagnosis;
- reveal every relevant pattern;
- remove the reason to upgrade.

**Primary CTA:** Unlock Personal Validation.

### Package 2 — 99 BAHT — PERSONAL VALIDATION

**Role:** Validate whether the detected pattern is relevant in the user's real life.

**User receives:**
- deeper pattern analysis
- self-assessment questions
- behavioral questions
- user examples / recent-event prompts
- Pattern Confidence: Low / Moderate / Strong
- strengths and blind spots
- practical implications

**Primary CTA:** Build My Life Action Plan.

### Package 3 — 599 BAHT — LIFE ACTION PLAN

**Role:** Convert validated patterns into behavior-change actions.

**User receives:**
- prioritized problem/pattern
- evidence-based self-development method from the Intervention Library
- personalized objective
- 7/14/30-day action plan depending on problem scope
- worksheets
- daily/weekly actions
- check-in prompts
- simple progress measurement

**Primary CTA:** Start Personal Transformation.

### Package 4 — 1,999 BAHT — PERSONAL TRANSFORMATION

**Role:** Ongoing structured transformation rather than a one-time report.

**User receives:**
- deep pattern analysis
- multiple prioritized patterns
- 30/60/90-day plan
- worksheets and exercises
- tracking dashboard
- weekly review
- progress score
- plan adjustment
- optional deeper natal/Uranian/transit timing layers

**Future premium extension:** Human + AI Coaching.

## 5. Conversion Objective

North-star commercial target:

> At least 80% of users who meaningfully complete the FREE experience should upgrade to a paid package.

This is a target, not an assumed market fact.

The product must measure and optimize:

```text
Free Start
→ Free Completion
→ Free → 99 Conversion
→ 99 → 599 Conversion
→ 599 → 1,999 Conversion
```

Optimization principle:

> Free creates curiosity and self-recognition; paid products provide validation, action, and transformation.

## 6. Core Features

### Astrology Engine
- Natal chart
- planets
- signs
- houses
- ASC / MC
- house rulers
- aspects
- retrograde
- Chiron / Node
- Uranian principles
- midpoints / planetary pictures
- transit
- timing

### Pattern Engine
Converts deterministic astrological evidence into potential life patterns.

Output must use language such as:
- Pattern to Explore
- Potential Pattern
- Possible Blind Spot

Do not present these as clinical diagnoses.

### Validation Engine
Combines:
- astrological signal;
- self-assessment;
- behavioral evidence;
- user context.

Produces a confidence level and explanation.

### Psychology / Intervention Engine
Uses a curated library of structured, evidence-based self-development interventions.

Each intervention should store:
- problem/pattern
- mechanism
- method
- exercise
- worksheet
- duration
- measurement
- evidence source
- applicability/limits
- safety notes

### Life Plan Engine
Converts a validated pattern into a concrete sequence of actions.

### Worksheet Engine
Provides structured exercises such as:
- thought record
- comfort-zone challenge
- values clarification
- implementation intention
- goal worksheet
- behavioral experiment

### Tracking Engine
Tracks:
- action completion
- check-ins
- scores
- weekly review
- progress
- plan adjustments

## 7. User Experience Principle

The user should never finish a report and wonder:

> "แล้วฉันต้องทำอะไร?"

Every paid level must end with a clear next action.

Target progression:

```text
Insight
→ Validation
→ Understanding
→ Action
→ Tracking
→ Growth
```

## 9. Primary Target Audience

Primary audience:
- adults approximately 25–45;
- people who feel they have more potential than they are currently using;
- people facing career stagnation or change;
- business owners / professionals;
- self-development oriented users;
- users who know they have a problem but do not know what to do next.

Core persona:

> "ฉันรู้ว่าตัวเองน่าจะทำได้มากกว่านี้ แต่ไม่รู้ว่าอะไรฉุดฉันไว้"

## 10. Content Strategy

Lead with real-life pain, not astrology terminology.

Example:

> ทำไมบางคนรู้ว่าตัวเองควรเปลี่ยน แต่กลับไม่เปลี่ยน?

Then:
1. Astrology insight
2. Psychology/self-development explanation
3. One practical exercise
4. CTA to FREE INSIGHT

## 11. Product Metrics

The system must support measurement of:
- report completion;
- assessment completion;
- package conversion;
- plan acceptance;
- action completion;
- 7-day retention;
- 30-day retention;
- user-reported progress.

## 12. Safety Boundary

Astro-Zodiac is a personal-development product.

It must not claim that astrology can clinically diagnose mental disorders or replace qualified mental-health care.

The system should use astrology/Uranian output as exploratory pattern signals and use structured self-assessment and behavioral evidence before generating stronger personal-development recommendations.

Escalation/safety messaging should be available when users report serious distress, self-harm risk, abuse, or other situations beyond the product's scope.

## 13. Product Success Definition

Astro-Zodiac succeeds when a user can move from:

```text
"ฉันมีปัญหาอะไร?"
        ↓
"นี่คือ Pattern ของฉัน"
        ↓
"ใช่ มันเกิดขึ้นในชีวิตจริง"
        ↓
"ฉันรู้ว่าต้องแก้อย่างไร"
        ↓
"ฉันมีแผนที่จะลงมือทำ"
        ↓
"ฉันเห็นว่าตัวเองเปลี่ยนแปลง"
```

The product is therefore an action-oriented personal-development system, not a report-only astrology application.
