# T21.1 — PostgreSQL First Runtime

PostgreSQL is the only runtime persistence backend for Development, Staging,
and Production.

`InMemory*Repository` classes remain test doubles only. The runtime persistence
factory does not expose a memory fallback.

Required runtime setting:

```text
ASTRO_ZODIAC_PERSISTENCE=postgres
DATABASE_URL=<PostgreSQL URL>
```

The API fails fast when configuration is invalid and `/health` performs an
actual database connectivity check.
