# T24.3 — FastAPI Bearer Auth / Swagger Integration

## Objective

Add a standard OpenAPI HTTP Bearer security scheme so Swagger UI exposes
the `Authorize` button and sends the login token as:

`Authorization: Bearer <access_token>`

## Boundary

- This does not change password hashing.
- This does not change session persistence.
- This does not change T12 entitlement rules.
- This only supplies the bearer-token extraction layer required by FastAPI
  OpenAPI/Swagger and the protected route adapter.

## Swagger flow

```text
POST /api/v1/auth/login
      ↓
  access_token
      ↓
   Authorize
      ↓
GET /api/v1/me
      ↓
   Bearer token
      ↓
  Session resolver
```

## Security requirement

Protected endpoints must declare:

`token: str = Depends(extract_bearer_token)`

and pass that token to the existing session/user resolver.

Do not store the token in application globals.
